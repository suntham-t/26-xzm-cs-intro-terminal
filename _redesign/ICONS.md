## 1. 用法

```js
el.innerHTML = icon('search');                  // 默认 1.05em，跟着字号走
'<button class="tb">' + icon('play','ico-16') + ' 可视化</button>'
icon('这个图标不存在');                         // → ''（空串，不抛错）
emojiToIcon('🧪 用样例测');                    // → '<svg …> 用样例测'
```

- `icon(name, cls?)`：未知 name 返回 `''`。**故意不抛错** —— 界面重试/半渲染时少一个图标可以接受，白屏不行。
- `hasIcon(name)`：给自检脚本和预览页用。
- `emojiToIcon(text)`：一次性把 UI 文案里的 emoji 换成图标（正文别用，见 §5）。
- 图标名全小写 kebab-case、语义命名（`play` 而不是 `triangle`）。

## 2. 硬约定（改图标前先读）

1. **同一个视觉盒子**：主体落在 3～21 之间（个别圆/方到 3.4～20.6）。
2. **线宽 1.8、圆角端点**：由外壳统一给，路径里不要再写 `stroke-width`。
3. **实心元素必须显式 `fill="currentColor" stroke="none"`**：外层是 `fill="none"`，不写就是空心的。
4. **细节直径别小于 2px**（24 网格里）：图标要在 16px 下认得出，宁可少一根线。
5. 不写颜色、不写宽高、不写 title 标签：外壳带 `aria-hidden="true"`，语义由按钮的 `aria-label` 给。
6. 一个图标只表达一个意思；表达不了就用「文字 + 现成图标」，不要硬造。

> `sliders` 是 `settings` 的别名（同一段路径）。这个 app 的「设置」本质是一排滑杆/输入框，
> 所以没做齿轮：20 齿的齿轮在 16px 下必然糊成一团，而原来左侧图标栏用的就是「三横 + 三个钮」这套。

### 4.2 逐条明细

判定口径（按优先级）：

| 判定 | 含义 | 该怎么做 |
|---|---|---|
| 注释 | emoji 在源码注释里 | 不影响界面；顺手删掉（源码里少些非 ASCII 更好） |

## 5. 替换约定（Lead 改 `web/index.html` 时照这个走）

### 5.1 可以直接 `icon()` 的地方

- JS 拼出来、最终 `innerHTML` 进 DOM 的**按钮 / chip / 分组头 / 空态 / 徽标**。
- 图标栏静态 SVG：换成 `icon('toc')` 等，class 仍用 `sbi`，尺寸由 `.sb svg` 定。
- 卡片标题旁的展示图标：`'<h2 class="cardTitle">' + icon('target','ico-20') + ' 本章要学什么'`。
  但**能不用就别用** —— 一屏之内图标越少越贵。

### 5.2 不能塞 `icon()` 的地方（会被转义 / 被当纯文本）

| 位置 | 为什么（源码位置） | 怎么办 |
|---|---|---|
| `openModal(kind, title, …)` / `openDaysMd()` 的 title | `panelHead` 里是 `innerHTML = escapeHtml(title)`（web/index.html:6893、:6864，生成本文件时现查） | 删掉标题 emoji；要图标就加 `opts.icon` 渲染到标题前 |
| `toast(msg)` | 里面已经是 `innerHTML = emojiToIcon(escapeHtml(msg))`（:0） | **不用手改**：toast 文案里的 emoji 渲染时自动变图标 |
| `title=` / `aria-label=` / `data-tip=` | 属性文本，塞 SVG 只会读出标签名 | 删 emoji；图标放可见标签上 |
| markdown 原文 / AI 回复 / 题面 / 解析 / 日志 | 是**内容**不是界面 | 一动不动（见 §4 的「保留」） |

### 5.3 两个完整例子

```js
// 改前（codeBlock() 里拼卡片代码块工具条那行）
'<button class="tb" data-act="cardviz" ...>▶ 可视化</button>'
// 改后
'<button class="tb" data-act="cardviz" ...>' + icon('play') + ' 可视化</button>'

// 改前（hwTestHtml() 里拼「生成边界用例」按钮那行）
(cs.busy ? "🤖 正在出题…" : "🤖 生成边界用例")
// 改后
(cs.busy ? icon('loader') + ' 正在出题…' : icon('robot') + ' 生成边界用例')
```
